Supabase belum diatur

Halaman admin butuh koneksi ke proyek Supabase.

  1. Buka file assets/config.js.
  2. Isi supabaseUrl dan supabaseAnonKey dari Supabase, menu Project Settings > API.
  3. Unggah ulang file itu, lalu muat ulang halaman ini.
